### Added
- Initial release of `logAnalyzer`.
- Core features:
  - Log parsing from files and standard input.
  - Stream processing for large files with minimal memory usage.
  - Advanced filtering: by level, time range, keywords, regular expressions, and complex boolean expressions.
  - Flexible data export to multiple formats: JSON, plain text, CSV, and XML.
  - Built-in statistical analysis to generate insights from log data.
